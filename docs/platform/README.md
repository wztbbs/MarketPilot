# 底座文档

底座位于 `com.cexpilot.platform`，提供公共 Agent 契约、执行引擎、工具控制和持久化运行。当前仍与 CEX 业务处于同一 Maven 工程、同一主应用中。

| 文档 | 范围 |
| --- | --- |
| [底座架构](底座架构.md) | 各层职责、引擎与运行的区别、自驱动执行、状态及扩展边界 |
| [包结构与依赖](底座隔离与演进.md) | package 分层、依赖方向、公共输入输出和业务扩展端口 |
| [HTTP 工具与声明式 Agent 接入](HTTP工具与声明式Agent接入.md) | YAML、受控 HTTP 服务、参数契约、Prompt 和引擎选择 |
| [方案审批与分阶段执行](方案审批与分阶段执行.md) | 工具调用方案、统一审批、执行约束、等待恢复和接入范围 |
| [方案审批 Demo 验证](Demo验证.md) | 默认关闭开关、测试访客白名单、模拟工具与手工验收步骤 |
| [异常处理约定](异常处理约定.md) | 入口与执行边界、异常分类、日志归属、事务和恢复的关系 |

CEX 的私有执行状态、Monitor 审批卡片和后台排期见 [CEX 文档](../cex/README.md)。底座接口由这些业务实现，不直接依赖对应业务类型。
